# Vehicle Upgrade System

Enhance your vehicles with professional automotive upgrades

## Features

- 6 engine components with variants
- Anti-exploit measures
- qb-target and ox_lib integration

## Requirements

- QB-Core
- qb-target
- ox_lib

## Installation

1. Download the script
2. Add the script to your resources folder
3. Add `ensure MechanicUpgradeSystem` to your server.cfg

## Usage

1. Open the vehicle hood
2. Use the mechanic toolkit
3. Select the component to upgrade

## Configuration

The script can be configured in the `config.lua` file. You can adjust the performance and price of each component variant, as well as the anti-exploit measures.
